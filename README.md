# Cinema Land

Cinema Land — это современный онлайн-кинотеатр, построенный на базе микрофронтенд-архитектуры.
🛠 Стек технологий
• Frontend: React, Next.js, Tailwind CSS, Material UI (MUI)
• Backend & Database: PostgreSQL
• Architecture: Nx Monorepo

📂 Структура проекта
Проект разделен на два ключевых приложения в рамках единого репозитория:

1. Cinema Land Admin — административная панель, предназначенная для управления контентом и добавления новых фильмов
   
2. Cinema Land Site — клиентский портал для пользователей, включающий поиск, фильтрацию и просмотр фильмо
